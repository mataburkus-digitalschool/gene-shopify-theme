# GENE — Shopify theme (grid sekce)

Kompletní Shopify motiv obchodu **kkt20k-st** (`shopify-grid-sekce`).
Sekce `gene-*` mají CSS vložené inline (žádná složka assets/snippets — motiv je soběstačný).

Homepage sekce (templates/index.json): hero · trust · countdown · grid_sale · bundles ·
collections · grid_new · marquee · why · reviews · banner · faq · email.

Napojení na Shopify: Online Store → Themes → Add theme → Connect from GitHub → branch `main`.
